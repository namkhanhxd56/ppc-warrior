3️⃣ SP — Chiến lược bid & loại campaign

1 keyword × 1 mức bid = 1 campaign. Số mức = số campaign tạo cho mỗi keyword với bid giảm dần · Bước nhảy = khoảng cách giữa các mức. VD bid gốc 0.78, số mức 3, bước 0.02 → 3 campaign: 0.78 / 0.76 / 0.74 (rải bid tìm mức thắng auction rẻ nhất).

3️⃣b SB — Sponsored Brands sắp ra mắt

Cần file bulk SB mẫu (đã tải từ Amazon Ads) để dựng đúng cấu trúc khối dòng — như đã làm với SP. Bạn tải 1 file bulk có sheet "Sponsored Brands Campaigns" đầy đủ campaign mẫu rồi gửi vào thư mục dự án, tôi sẽ build phần này.

3️⃣c SD — Sponsored Display sắp ra mắt

Tương tự SB — cần file bulk SD mẫu để dựng cấu trúc chính xác.

4️⃣ Tên campaign

Placeholder: {ASIN} {SKU} {Keyword} {MatchType} {Bid} {StartDate} {Name} {TargetAsin} {AdType} {Category} {Note} — field trống tự bỏ
