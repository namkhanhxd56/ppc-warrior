1️⃣ Import file bulk (ảnh chụp tài khoản)

Tải file bulk từ Amazon Ads (nên chọn giai đoạn 14–60 ngày + tick Search Term Report khi tải). File lớn (30-40MB) xử lý mất ~10-30 giây. Số liệu 1 ngày quá nhiễu để quyết định bid/budget — dùng file tổng giai đoạn.

2️⃣ Điều chỉnh — mọi thay đổi gom vào tab 📋 Thay đổi, xuất 1 file bulk để upload ngược lại Amazon

Sắp xếp:
Entity: bấm nhiều nút để gộp · Target = Keyword + Product Targeting
🔎

📜 Nhật ký chỉnh sửa (các file Update đã xuất)

Mỗi lần bấm Lưu & Tải file Update đều được ghi lại: thời điểm, dataset, nguồn (tự sửa / rule), số thay đổi + negative. Bấm 1 dòng để xem chi tiết old→new.

🚀 Tạo Campaign với keyword

Mỗi search term = campaign Exact mới cho ASIN đó — tên campaign / ad group theo rule đặt tên đã lưu ở trang Tạo Campaign. Bid mặc định = CPC — sửa được. Bấm nút là xếp vào module 📋 Thay đổi (không tải file ngay) — xem nhiều search term rồi xuất 1 lần.
